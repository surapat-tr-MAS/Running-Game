# Running Game — เกมวิ่งแข่งจับจังหวะ WASD

เกมวิ่งแข่งแบบเรียลไทม์ผ่านเครือข่ายภายใน (Wi-Fi / LAN) เล่นพร้อมกันได้สูงสุด **8 ลู่ต่อรอบ**  
ผู้เล่นทุกคนใช้แค่เว็บเบราว์เซอร์บนคอมพิวเตอร์ แท็บเล็ต หรือมือถือ **ไม่ต้องติดตั้งโปรแกรมเพิ่มเติม และไม่ต้องใช้อินเทอร์เน็ตระหว่างเล่น**

* **โหมดภาพ 3 มิติ** สนามกรีฑา 8 ลู่ พร้อมนักวิ่งขยับแขนขาสปีดตามความเร็วจริง และ **โหมด 2 มิติ (`?2d=1`)** สำหรับเครื่องสเปกเก่า
* **ระบบจับจังหวะ WASD (60fps):** กดตรงจังหวะวิ่งเร็วขึ้นและปุ่มไวขึ้นเรื่อย ๆ · กดพลาดหรือปล่อยหลุดความเร็วตกทันทีและรีเซ็ตจังหวะกลับช้าสุด
* **หน้าจอโฮสต์/โปรเจกเตอร์ (`/host.html`):** ใช้คุมการแบ่งสาย ปรับระยะทาง เพิ่มบอทซ้อมวิ่ง และฉายอันดับสดขึ้นจอใหญ่

---

## เริ่มใช้งาน

### ข้อกำหนดเบื้องต้น
* ติดตั้ง **Node.js รุ่น 18 ขึ้นไป** (แนะนำรุ่น LTS จาก https://nodejs.org) บนเครื่องที่จะเปิดเป็นเซิร์ฟเวอร์ (เครื่องโฮสต์/ครู)

### วิธีที่ 1: เปิดใช้งานทันทีบน Windows (แนะนำ)
1. ดับเบิลคลิกไฟล์ `start.bat`
2. หากเปิดครั้งแรกและยังไม่มี `node_modules` ตัวสคริปต์จะติดตั้งแพ็กเกจที่จำเป็นให้โดยอัตโนมัติ (ต้องต่ออินเทอร์เน็ตเฉพาะครั้งแรก)
3. หน้าต่างคำสั่งจะแสดงที่อยู่สำหรับผู้เล่นและ **PIN ของโฮสต์** เช่น:

```text
============================================================
  Running Game — เกมวิ่งแข่งจับจังหวะ WASD
============================================================

  ลิงก์สำหรับผู้เล่น (เปิดในเบราว์เซอร์):

      http://192.168.1.50:3100

  จอควบคุมของโฮสต์ / โปรเจกเตอร์ (เปิดในเครื่องนี้):

      http://localhost:3100/host.html

  PIN สำหรับจอควบคุม:  4821

  *** อย่าปิดหน้าต่างนี้ระหว่างเล่น ***
============================================================
```

### วิธีที่ 2: เปิดผ่าน Command Line
```bash
npm install        # ทำครั้งแรก (หรือเพิ่ม npm run vendor หากอัปเดต three.js)
npm start          # เปิดเซิร์ฟเวอร์
```

#### กำหนดพอร์ตหรือ PIN เอง
* **Command Prompt (`cmd`):**
  ```cmd
  set PORT=8080
  set HOST_PIN=1234
  node server.js
  ```
* **PowerShell:**
  ```powershell
  $env:PORT="8080"; $env:HOST_PIN="1234"; node server.js
  ```

> **หากผู้เล่นเครื่องอื่นเข้าไม่ได้:** มักเกิดจาก Windows Defender Firewall บล็อก Node.js  
> เมื่อเปิดครั้งแรกให้กด **Allow access (อนุญาต)** หากเผลอกดปฏิเสธ ให้เปิด *Windows Defender Firewall → Allow an app through firewall* แล้วติ๊กอนุญาต `Node.js` บนเครือข่าย Private/Public ที่ใช้งานอยู่

## ขั้นตอนการจัดแข่ง (สำหรับโฮสต์ / ครู)

1. โฮสต์เปิด `http://localhost:3100/host.html` แล้วใส่ **PIN 4 หลัก** ที่ขึ้นในหน้าต่างคำสั่ง
2. แจ้งลิงก์ `http://<IP เครื่องโฮสต์>:3100` ให้ผู้เล่นเปิดในเบราว์เซอร์แล้วใส่ชื่อเข้าร่วม
3. *(ตัวเลือก)* ปรับ **ระยะทางสนามวิ่ง** (`150` / `250` / `350` / `500` เมตร) และกดเพิ่ม **บอทซ้อมวิ่ง** (`3` / `5` / `7` ตัว) หากต้องการเติมลู่ให้เต็มหรือซ้อมคนเดียว
4. ตั้งจำนวน **คนต่อสาย** (`1`–`8`) แล้วกด **สุ่มแบ่งสาย**
5. กด **เริ่มสายที่ 1** (ระบบจะนับถอยหลัง 5 วินาทีก่อนปล่อยตัวอัตโนมัติ)
6. เมื่อแข่งครบทุกสาย สามารถกด **ตั้งรอบชิง (คะแนนสูงสุด)** เพื่อดึงผู้เล่นคะแนนสูงสุดมาชิงชนะเลิศในรอบสุดท้ายได้

## กติกา กลไกจังหวะ และคะแนน

### ระบบความเร็วและจังหวะ WASD
| สถานการณ์ | ผลต่อความเร็วนักวิ่ง | ผลต่อความไวชุดปุ่ม (Tempo) |
|---|---|---|
| **เริ่มออกตัว** | `4.0 m/s` | `Lv.1` (`1100 ms` ≈ 55 BPM) |
| **กดตรงจังหวะ (`PERFECT`)** | เร่งความเร็วขึ้นมาก (สูงสุด `19.0 m/s`) | เพิ่มคอมโบ + ปุ่มค่อย ๆ ไวขึ้นทีละขั้น (`Lv.1 → Lv.15`) |
| **กดเข้าจังหวะ (`GOOD`)** | เร่งความเร็วขึ้นปานกลาง | เพิ่มคอมโบ + ปุ่มค่อย ๆ ไวขึ้นทีละขั้น |
| **กดผิดปุ่ม / กดนอกจังหวะ / ปล่อยหลุด (`MISS`)** | สะดุดทันที ความเร็วลดเหลือ `44%` (ต่ำสุด `1.4 m/s`) | คอมโบเป็น `0` และ **Reset ความไวปุ่มกลับเป็นช้าสุด (`Lv.1` / `1100 ms`)** |

* ช่วง `Lv.1` (`1100 ms`) ถึง `Lv.15` (`340 ms` ≈ 176 BPM) ความเร็วปุ่มจะค่อย ๆ ไต่ระดับแบบนุ่มนวลตามจำนวนคอมโบที่กดถูกต่อเนื่อง
* กรอบเวลาตัดสิน (`PERFECT` / `GOOD`) ปรับตามระดับความไวปัจจุบัน (`±71`–`±85 ms` สำหรับ Perfect และ `±129`–`±175 ms` สำหรับ Good)
* แต่ละรอบจำกัดเวลาสูงสุด `90` วินาที (หรือจบทันทีเมื่อนักวิ่งทุกคนเข้าเส้นชัยครบ)

### คะแนนและการจัดอันดับ
* **อันดับในรอบ:** จัดอันดับตาม **เวลาเข้าเส้นชัย** ที่เร็วที่สุด (หากยังเข้าไม่ครบเมื่อหมดเวลา จัดตาม **ระยะทางที่วิ่งได้**)
* **คะแนนจากการกดจังหวะ:**
  * `PERFECT`: `+12` คะแนน + โบนัสคอมโบ (สูงสุด `+24`)
  * `GOOD`: `+7` คะแนน + โบนัสคอมโบ (สูงสุด `+14`)
* **โบนัสอันดับเมื่อเข้าเส้นชัย (อันดับ 1–8):** `+100`, `+75`, `+55`, `+40`, `+30`, `+20`, `+15`, `+10` คะแนน

## การควบคุม

* **คีย์บอร์ด:**
  * `W` `A` `S` `D` หรือปุ่มลูกศร `↑` `←` `↓` `→` — กดตามสัญลักษณ์ที่วิ่งเข้าสู่วงเป้าหมาย
  * `C` — สลับมุมกล้องระหว่าง **ตามตัวเรา** และ **มุมกว้างทั้งสนาม**
* **มือถือ / แท็บเล็ต / เมาส์:**
  * กดปุ่ม `W ▲` `A ◀` `S ▼` `D ▶` บนหน้าจอได้โดยตรง
* **ปุ่มมุมขวาบนในสนาม:** เปิด/ปิดเสียงสังเคราะห์ (`เสียง: เปิด/ปิด`), สลับมุมกล้อง, สลับโหมดภาพ (`3 มิติ` / `โหมดประหยัด`)

## ทดลองเล่นคนเดียวและทดสอบระบบ

### 1. เพิ่มบอทจากหน้าจอโฮสต์ (ง่ายที่สุด)
เปิด `/host.html` → กดเลือกจำนวนบอท `3 / 5 / 7 ตัว` → กด **สุ่มแบ่งสาย** → กด **เริ่มสายที่ 1**

### 2. เพิ่มบอทผ่าน Command Line
```bash
node test/bots.mjs <PIN>            # เพิ่มบอท 5 ตัว แล้วเริ่มแข่งทันที
node test/bots.mjs <PIN> 7          # เพิ่มบอท 7 ตัว แล้วเริ่มแข่งทันที
node test/bots.mjs <PIN> 5 join     # เพิ่มบอท 5 ตัว รอโฮสต์กดเริ่มเอง
```

### 3. รันชุดทดสอบอัตโนมัติ (End-to-End Test)
เปิดเซิร์ฟเวอร์ในหน้าต่างที่ 1 (`HOST_PIN=1234 npm start`) แล้วรันในหน้าต่างที่ 2:
```bash
node test/e2e.mjs 1234 http://localhost:3100
```

## หลักการออกแบบสำคัญ

* **Server-Authoritative:** ฝั่งเบราว์เซอร์ส่งเพียงเหตุการณ์กดปุ่ม (`tap`) และเวลาที่ซิงค์กับเซิร์ฟเวอร์ การคำนวณระยะทาง ความเร็ว การพลาด และอันดับเกิดขึ้นที่เซิร์ฟเวอร์ทั้งหมด
* **Clock Synchronization (`time:ping`):** ไคลเอนต์วัดค่าความต่างนาฬิกาและ RTT กับเซิร์ฟเวอร์ตลอดเวลา เพื่อให้ตัวโน้ตบนรางจังหวะวิ่งตรงกันแม้เล่นผ่าน Wi-Fi ที่มีดีเลย์
* **Fixed-Timestep Accumulator:** ใช้ `process.hrtime.bigint()` ใน `server.js` เพื่อคุมความเร็วลูปฟิสิกส์ที่ `20 Hz` ให้เดินตรงกับเวลาจริงแม้บน Windows
* **ประหยัดแบนด์วิดท์:** ส่งสถานะสนามแบบอาร์เรย์ตัวเลขย่อ (`20 Hz` สำหรับผู้เล่นในรอบ และ `10 Hz` สำหรับผู้ชม) พร้อมเกลี่ยภาพลื่นไหล 60fps ฝั่งไคลเอนต์
* **ทนเน็ตหลุด:** เก็บ `token` ผู้เล่นใน `localStorage` เมื่อรีเฟรชหน้าจอหรือหลุดกลางรอบ สามารถต่อกลับเข้าลู่และคะแนนเดิมได้ทันที

## ปัญหาที่พบบ่อย

* **ผู้เล่นเข้า IP แรกไม่ได้:** ลองดูหัวข้อ *"หากเข้าด้วยลิงก์ด้านบนไม่ได้"* ในหน้าต่างดำ แล้วใช้ IP จากการ์ดเครือข่าย Wi-Fi/LAN ตัวจริงแทนการ์ดเสมือน (เช่น VirtualBox / VMware / Tailscale) และตรวจว่าอยู่ Wi-Fi วงเดียวกัน
* **พอร์ต `3100` ถูกใช้งานอยู่แล้ว** (เช่น เปิดเกมอื่นค้างไว้): เปลี่ยนพอร์ตก่อนเปิดด้วย `set PORT=3200` (cmd) หรือ `$env:PORT="3200"` (PowerShell)
* **มีชื่อคนที่ปิดจอไปแล้วค้างในล็อบบี้:** ระบบจะลบผู้เล่นที่ยังไม่เคยแข่งอัตโนมัติใน 3 นาที หรือโฮสต์กดปุ่ม **ลบคนที่หลุด** บนหน้า `/host.html` ได้ทันที
